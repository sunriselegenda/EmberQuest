# Отчёт о проверке Ember Quest

Проверка исходного проекта: 20 ноября 2026 года.

Окружение: Linux, Python 3.12.14, Pygame 2.6.1; драйверы SDL `dummy` для видео и звука. Готовый Windows EXE не собирался и не проверялся. Реальное аудиоустройство в этой среде не прослушивалось.

## Автоматические проверки

Команда: `python -m unittest discover -s tests -v` из папки проекта.

| Проверка | Результат |
|---|---|
| Цикл красный → синий → зелёный → красный | Пройдено |
| Подбор только совпадающего ключа; переключение стоя на нём | Пройдено |
| Цвет и ключ для двери; однократное расходование | Пройдено |
| Стены, шипы, кристалл, завершение и запрет шагов после победы | Пройдено |
| Все шесть карт с полным сбором кристаллов | Пройдено |
| Два одинаковых ключа и две последовательные двери | Пройдено |
| Загрузка прогресса и сохранение лучшего результата | Пройдено |
| Восстановление после некорректного JSON | Пройдено |
| Рендеринг экранов, пробел, пауза, перезапуск, помощь, завершение | Пройдено |

## Визуальная проверка

Выполнен запуск генерации кадров меню и шестого уровня. Изображения `menu.png` и `gameplay.png` просмотрены: текст с кириллицей, инвентарь, предметы, герой и границы карты отображаются. Проверка экранов дополнительно выполнена вызовами реального рендеринга Pygame в тесте.

Перед сдачей рекомендуется один раз запустить проект на компьютере защиты, проверить клавиатуру, размер окна и звук, а также отдельно проверить EXE, если используется сборка.
