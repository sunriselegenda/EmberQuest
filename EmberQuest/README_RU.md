# Ember Quest — Храм трёх огней

Готовый учебный 2D-проект на **Python + Pygame**, вид сверху. Герой — последняя искра древнего храма. Чтобы добраться до портала, нужно менять цвет, собирать подходящие ключи и снимать цветные печати с дверей.

## Быстрый запуск на Windows

1. Установи **Python 3.12** с https://www.python.org/downloads/ (при установке включи **Add python.exe to PATH**). Для воспроизводимого запуска рекомендуется именно 3.12.
2. Полностью распакуй архив. Не запускай игру прямо из ZIP.
3. Дважды нажми **start_windows.bat**.
4. При первом запуске скрипт создаст локальное виртуальное окружение и установит Pygame. Нужен интернет. Последующие запуски работают без интернета.

Другой способ: открой терминал в папке проекта и выполни:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Если работаешь в PyCharm / VS Code, выбери интерпретатор `.venv\Scripts\python.exe` и запусти `main.py`. Рабочая директория может быть любой: ассеты находятся относительно файлов проекта.

**Linux / macOS:** `sh start.sh` либо `python3 -m pip install -r requirements.txt`, затем `python3 main.py`. На Linux пакет venv иногда устанавливается отдельно средствами ОС.

## Правила

- Цвета переключаются по кругу: **красный → синий → зелёный → красный**.
- Ключ подбирается только героем **того же цвета**. Если стоишь на ключе, достаточно переключиться в нужный цвет.
- Для открытия двери нужны **ключ её цвета и совпадающий цвет героя**.
- Открытие расходует **один ключ**. Дверь остаётся открытой до перезапуска уровня.
- Ключи одинаковых цветов складываются в инвентаре.
- Светящийся портал завершает уровень. Кристаллы необязательны.
- Шипы и движущиеся огненные стражи возвращают в начало текущего уровня. Собранные на нём предметы восстанавливаются; счётчик возрождений увеличивается, время не сбрасывается.
- На первых уровнях опасностей нет. Их добавляют постепенно.
- Число жизней не ограничено.

**Звёзды:** одна за завершение уровня, ещё одна за все кристаллы, ещё одна за прохождение без возрождений и перезапуска через R. Лучший результат сохраняется.

Цвета дополнительно обозначены узорами: **красный — круг; синий — ромб; зелёный — треугольник** на дверях.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки | Движение |
| Пробел | Следующий цвет |
| R | Начать текущий уровень заново |
| Esc / P | Пауза / продолжить |
| F1 | Правила |
| M | Выключить / включить звук |
| Enter | Продолжить из меню / перейти к следующему уровню после победы |
| ← →, Enter | Выбор и запуск открытого уровня в меню уровней |
| Мышь | Кнопки меню |

Окно изменяет размер, пропорции сохраняются. Скорость игры рассчитывается по времени между кадрами. Во время паузы не двигаются герой и стражи, не идёт секундомер.

## Что входит в проект

- Шесть последовательно открывающихся уровней.
- Анимированный герой трёх цветов; отдельные PNG-спрайты ключей, дверей, стен, пола, факелов, портала, кристаллов, шипов и стражей.
- Пиксельная графика создана для этого проекта программно; генератор исходных ассетов включён.
- Семь звуковых эффектов и фоновый ambient loop в WAV. Нет зависимости от внешних музыкальных сервисов.
- Главное меню, выбор уровня, правила, пауза, экран результата.
- Инвентарь, подсказки, частицы, свет, таймер, кристаллы и звёзды.
- Сохранение открытых уровней, лучших звёзд и настройки звука.
- Автотесты правил, сохранений и запуска интерфейса.
- Описание архитектуры, алгоритмов и материал для защиты.

## Сохранения

Прогресс лежит в `~/.ember_quest/progress.json` — на Windows обычно `C:\Users\имя\.ember_quest\progress.json`. Он переживает закрытие игры. Уровень посреди прохождения не сохраняется: при выходе возвращается к началу.

Чтобы сбросить прогресс, закрой игру и удали этот JSON. Для изолированного тестирования можно задать переменную среды `EMBER_QUEST_SAVE_DIR`.

Если файл повреждён, игра загружает доступные настройки либо использует начальные значения. Если запись запрещена, игра продолжает работать и показывает сообщение.

## Изменение карт

Карты находятся в `assets/levels.json`. Каждая строка — ряд клеток. Все строки одной карты должны быть одинаковой длины. Текущий интерфейс рассчитан на карты **31 × 17 клеток**, размер клетки 32 px. Для карт другого размера нужно менять компоновку в `game.py`.

| Символ | Значение |
|---|---|
| `#` | Стена |
| `.` | Пол |
| `S` | Начало: ровно одно на карте |
| `E` | Выход: ровно один на карте |
| `r`, `b`, `g` | Красный, синий, зелёный ключ |
| `R`, `B`, `G` | Дверь соответствующего цвета |
| `*` | Кристалл |
| `^` | Шипы |

`enemies` содержит точки `a`, `b` и скорость `speed` в клетках/сек. Включённые патрули горизонтальны. При редактировании убедись, что их маршрут не проходит сквозь стены или двери. Позиции задаются `[x, y]`, начиная с нуля.

Можно редактировать JSON напрямую. `tools/generate_levels.py` восстановит исходные карты и **перезапишет ручные изменения**. Аналогично `tools/generate_assets.py` восстановит исходные ассеты. Для генераторов нужна только установленная зависимость проекта.

## Проверка

Из папки проекта:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

В Linux: `python3 -m unittest discover -s tests -v`.

Тестовый поиск маршрутов проверяет возможность собрать все кристаллы и пройти все шесть карт, обходя шипы и целиком исключая линии патруля. Это не игровой автопилот: в обычной игре маршрутом управляет игрок.

## Сборка EXE на Windows (необязательно)

Сначала запусти игру через `start_windows.bat`, затем закрой её и запусти `build_exe_windows.bat`. Скрипт устанавливает PyInstaller и создаёт `dist\EmberQuest\EmberQuest.exe`.

Передавай **всю папку `dist\EmberQuest`**, включая `_internal`, а не только EXE. На компьютере получателя Python уже не нужен. Сам EXE в этот архив не включён: проект проверен из исходников в Linux, Windows-сборку нужно выполнить и проверить на Windows.

## Если не запускается

- `No module named pygame`: установи `requirements.txt` именно тем Python, которым запускаешь `main.py`.
- Ошибка установки зависимости: используй Python 3.12, проверь интернет и повтори установку.
- Нет графики / `FileNotFoundError`: распакуй весь архив; папка `assets` должна лежать рядом с `main.py`.
- Нет звука: нажми M. Если аудиоустройство недоступно, игра работает без звука.
- В окне не работают клавиши: щёлкни по окну игры, чтобы оно получило фокус.

Документация Pygame: https://www.pygame.org/docs/ ; установка: https://www.pygame.org/wiki/GettingStarted .
